# 心誠不動産 GitHub Pages

公開先: https://wbw49fgjpz-bot.github.io/-shinsei-home/

ビルド不要の静的サイト。main ブランチのルートを GitHub Pages で公開します。

- `index.html`: ページ本文、会社情報、SEO・SNSプレビュー設定
- `style.css`: スマホ優先のレイアウト、固定CTA、印刷・動きを減らす設定
- `site.js`: スマホメニューを閉じる操作と年表示（JavaScriptなしでも本文・リンク・FAQは利用可能）
- `og.jpg`: SNS共有用画像（AI生成）
- `shinsei-character.jpg`: 既存会社サイトのキャラクター
