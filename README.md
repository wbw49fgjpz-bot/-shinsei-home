予約台帳やサーバーへの送信機能はありません。必須入力と定休日（火・水）、過去日を確認し、内容プレビューとメール下書きリンクを作ります。利用者がメールアプリで送信し、担当者が確認して日時を調整します。画面上で予約完了を表示しません。JavaScript無効時はフォーム送信ボタンを無効化し、電話・メール・LINEを案内します。入力値はブラウザストレージに保存しません。
